Create a responsive Cake Raffle web application using HTML, CSS, and JavaScript.

Requirements:

- A modern and clean UI with soft pastel colors and rounded cards.
- The application title should be "Cake Raffle".
- Include an input field with the placeholder "Enter your name".
- Add an "Enter" button to add participants.
- Display all entered participants in a list below the form.
- Prevent duplicate names and empty submissions.
- Show the total number of participants.
- Include a "Draw" button that randomly selects one participant as the winner.
- Display the winner inside a highlighted winner card with a short celebration animation (confetti or bounce effect).
- After a winner is selected, disable the Draw button until the list changes.
- Include a "Reset" button that clears all participants and resets the application.
- Pressing the Enter key should also add a participant.
- Store participants in localStorage so they remain after refreshing the page.
- Make the design fully responsive for desktop, tablet, and mobile devices.
- Use smooth hover effects, transitions, and subtle animations.
- Write clean, well-organized HTML, CSS, and vanilla JavaScript only (no frameworks).
